# Stage 1 — Python Programming

## Overview

Stage 1 introduces Python, the primary programming language used throughout this curriculum.

The goal of this stage is to build strong programming fundamentals through consistent practice, problem-solving, and hands-on projects.

By the end of this stage, you should be able to write clean, readable Python programs and use Python confidently to solve real-world problems.

---

# Learning Outcomes

By the end of this stage, you should be able to:

- Understand Python syntax and core programming concepts.
- Write well-structured Python programs.
- Solve programming problems independently.
- Read and understand existing Python code.
- Use functions and modules effectively.
- Work with files and exceptions.
- Use object-oriented programming fundamentals.
- Write clean and maintainable code.
- Debug and test Python programs.
- Build small real-world Python projects.
