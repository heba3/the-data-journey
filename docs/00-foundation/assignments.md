# Stage 0 — Assignments

These assignments are designed to ensure that all essential tools and workflows are in place before starting Stage 1.

---

# Assignment 1 — Development Environment

## Objective

Set up a complete Python development environment.

### Requirements

- Install Python
- Install Visual Studio Code
- Install Git
- Configure Git
- Verify that everything works correctly

---

# Assignment 2 — GitHub Setup

## Objective

Become familiar with GitHub and the basic Git workflow.

### Requirements

- Create a GitHub repository
- Clone the repository locally
- Make at least three commits
- Push all changes to GitHub

---

# Assignment 3 — Markdown Practice

## Objective

Learn GitHub Markdown.

### Requirements

Create a Markdown document that includes:

- Headings
- Lists
- Tables
- Links
- Images
- Code blocks
- Checklists

---

# Assignment 4 — Repository Organization

## Objective

Organize the repository professionally.

### Requirements

- Improve the README
- Organize folders
- Follow consistent naming conventions
- Remove unnecessary files

---

# Assignment 5 — AI for Learning

## Objective

Use AI as a learning assistant.

### Requirements

Use AI to:

- Explain a programming concept
- Review a Markdown document
- Create a short quiz
- Summarize a technical article

Write a short reflection describing what was helpful and what required your own research.
