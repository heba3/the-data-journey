# Stage 0 — Weekly Plan

This stage is designed to prepare your learning environment and establish the habits and tools that will support the rest of your journey.

**Estimated Time:** 20 Hours

---

# Week 1

## Day 1 — Curriculum & Planning

### Topics

- Read the curriculum roadmap.
- Understand the learning journey.
- Set personal learning goals.
- Create a weekly study schedule.

### Tasks

- Read the repository structure.
- Write down your learning goals.
- Plan your weekly study hours.

---

## Day 2 — Development Environment

### Topics

- Install Python
- Install Visual Studio Code
- Install Git
- Configure Git

### Tasks

- Verify Python installation.
- Configure VS Code.
- Configure Git username and email.

---

## Day 3 — Git & GitHub

### Topics

- Git basics
- GitHub basics
- Repository workflow

### Tasks

- Create a GitHub repository.
- Clone the repository.
- Make your first commit.
- Push changes to GitHub.

---

## Day 4 — Markdown

### Topics

- Markdown syntax
- GitHub Flavored Markdown

### Tasks

Create a Markdown document containing:

- Headings
- Lists
- Tables
- Links
- Images
- Code blocks
- Checklists

## Day 5 — Project Organization

### Topics

- Folder structure
- Naming conventions
- Documentation
- README files

### Tasks

- Organize the repository.
- Improve the README.
- Review the folder structure.

---

## Day 6 — Using AI for Learning

### Topics

- Asking effective questions
- Debugging with AI
- Learning through explanations

- Practice asking AI to explain concepts.
