# Books

This document contains all textbooks used throughout **The Data Journey**.

The goal is to maintain a focused reading list that supports the curriculum without overwhelming the learner.

---

# Reading Priorities

| Priority | Description |
|----------|-------------|
| Core | Primary textbook. Must be completed. |
| Reference | Used for deeper understanding or clarification. |
| Optional | Additional reading for interested learners. |
