# Skill Matrix

This document defines every skill covered throughout **The Data Journey** curriculum.

Each skill is mapped to a learning stage, learning priority, and assessment.

---

# Skill Levels

| Priority | Description |
|----------|-------------|
| Core | Required before progressing to the next stage. |
| Important | Strongly recommended. |
| Optional | Useful but not required for Version 1.0. |
| Advanced | Intended for Version 2.0 or future specialization. |
