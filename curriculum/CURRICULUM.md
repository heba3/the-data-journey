# Curriculum

## Overview

This curriculum is designed as a structured, university-style learning path toward Data Analysis, Data Science, and Artificial Intelligence.

Rather than following isolated courses, the curriculum integrates carefully selected academic resources, hands-on projects, books, and continuous practice into one coherent learning journey.

The goal is to build both theoretical understanding and practical skills while maintaining a clear progression from foundational concepts to advanced topics.

---

# Curriculum Structure

| Stage | Focus | Main Topics |
|------|-------|-------------|
| 0 | Learning Foundations | Study skills, Git, GitHub, VS Code, Learning Strategy |
| 1 | Python Programming | Python fundamentals, problem solving, OOP |
| 2 | Computer Science | Computational thinking, algorithms, data structures (MIT 6.0001 & 6.0002) |
| 3 | Mathematics & Statistics | Linear Algebra, Calculus, Probability, Statistics |
| 4 | Data Analysis | SQL, Excel, Power BI, NumPy, Pandas, Data Cleaning, EDA |
| 5 | Machine Learning | Classical ML, Feature Engineering, Model Evaluation |
| 6 | Artificial Intelligence | MIT Universal AI, LLM Fundamentals, AI Ethics |
| 7 | Professional Development | Portfolio, Kaggle, Scientific Reading, Technical Writing, Capstone |

---

# Learning Principles

Every stage follows the same learning cycle:

1. Learn the theory.
2. Practice through exercises.
3. Build a project.
4. Reflect and document what was learned.
5. Complete a self-assessment before moving forward.

---

# Expected Outcomes

By completing this curriculum, I should be able to:

- Write clean Python programs.
- Solve computational problems.
- Analyze real-world datasets.
- Build interactive dashboards.
- Develop and evaluate machine learning models.
- Understand modern AI concepts.
- Create a professional portfolio.
- Be well prepared for graduate studies in Data Science.

---

# Assessment Strategy

Each stage includes:

- Weekly exercises
- Practical assignments
- Mini projects
- One capstone project
- Self-assessment checklist

Progression to the next stage should only happen after successfully completing the previous one.
